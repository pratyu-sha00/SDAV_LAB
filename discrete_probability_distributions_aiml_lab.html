Explore foundational discrete probability models essential for machine learning algorithms, data modeling, feature reliability analysis, and stochastic process simulations.

Binomial Distribution

Model number of successes in $n$ independent binary trials with probability $p$. Fully interactive PMF, CDF, and statistical analyzer.

Poisson Distribution

Model event counts occurring independently at a constant average rate $\lambda = n \cdot p$. Complete with PMF, CDF, and dynamic charts.

Geometric Distribution

Model trial number needed to get the first success in independent Bernoulli trials. Interactive PMF, CDF, and statistics.

Geometric Distribution

Note: $0 < p \le 1$. $p = 0$ is not allowed because the first success would never occur.
